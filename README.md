# Презентация «Ярослав Мудрый»

Тема 11 из списка по истории России (Киевская Русь, IX–XII вв.). 9 слайдов.

- `Yaroslav_Mudry.pptx` — презентация для PowerPoint / Google Slides (с заметками докладчика к каждому слайду)
- `Yaroslav_Mudry.pdf` — та же презентация в PDF
- `src/` — скрипт, которым собрана презентация (pptxgenjs)

Содержание: титул · происхождение · борьба за престол · внешняя политика · династические браки · «Русская Правда» · культура и просвещение · завещание · итоги.
